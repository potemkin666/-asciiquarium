# Credits

This project is a from-scratch reimplementation in Python + Pygame inspired by the
classic terminal program **asciiquarium** by **Kirk Baucom**
(<https://robobunny.com/projects/asciiquarium/>), originally written in Perl and
released under the GNU General Public License v2 or later.

Several of the ASCII art sprites (waterline, castle, seaweed, fish silhouettes,
shark, ship, whale, big fish, etc.) were adapted from the original `asciiquarium`
distribution and from public ASCII art collections. All such sprites are believed
to be freely shareable under the GPL-2.0-or-later terms applied to this repository.

If you are an author of any of the included artwork and would like attribution
adjusted or content removed, please open an issue on the project tracker.

## Tooling

- [pygame](https://www.pygame.org/) — rendering and event loop
- [PyInstaller](https://pyinstaller.org/) — packaging into double-clickable binaries
